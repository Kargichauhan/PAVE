        PLAYBOOK DECISION RULES
        • Strongly aligned when 90% or more of a grade's assessable standards rate exact or full at grade.
        • Re-calibrate when reviewer agreement before discussion falls below 80%.
        • Gaps route to triage: A item or task-model development, B resource curation, C standards conversation, D documentation.

        CHANGE REQUESTS

        My change requests

        Each request changes the state standard for one item. The current mapping stays in use until a Smarter Balanced reviewer approves it.

        1. 1 · ProposeA state user picks an item in Compare and proposes a candidate standard.
        2. 2 · ReviewIt lands in the Smarter Balanced review queue.
        3. 3 · ApproveA different person approves, rejects or sends it back with a note.
        4. 4 · PublishThe new standard replaces the old one for that item from then on.

        GOALS AND LIMITS
        PAVE assumptions and scope
        What PAVE will do, and what it will not do. Read this before sharing results from the demo.
        
        
        
          THE GOAL
          
        Show every Smarter Balanced item in each member state's own standards
        
          
        Each item is tagged once, in TIMS, with a CCSS standard. PAVE uses that CCSS standard as the meta standard and links each state's standards to it, so a state sees every item in its own standards language.
        
        
        
        
        
          
        
            WHAT PAVE DOES
        What you can count on
        
            
          
              
        • Shows items in your state's standards. Every item is shown with the state standard it maps to, through the CCSS meta standard.
          • 
              
        • Smarter Balanced reviews every change. A state proposes a change for one item, Smarter Balanced reviews it, and it is approved before it is used. Nothing goes live without review.
          • 
              
        • Any number of standards per meta standard. A state can link one, two or many of its standards to one CCSS standard (Idaho splits 3.RI.4 into three).
          • 
              
        • Item IDs never change. A change only moves which state standard an item maps to.
          • 
              
        • Additional grades. Each item shows any other grades its state standard applies to, and the wording table compares a state's wording with every tested grade.
          • 
              
        • Propose from where you are. Open an item anywhere in the app and propose a change for it right there.
          • 
            
        
          
        
          
        
            WHAT PAVE DOES NOT DO
        Out of scope
        
            
          
              
        • Does not write standards. PAVE never writes or auto-authors standards. People at the state write them.
          • 
              
        • Does not show item content. Secure items stay in TIMS. PAVE shows item IDs and standard text only, never the item itself.
          • 
              
        • Does not show other states. A state user sees only their own state. Only Smarter Balanced staff see every state.
          • 
              
        • No download or export yet. States cannot download their standards in this version.
          • 
              
        • No links to other Smarter Balanced apps yet. Sending mappings to reporting or to IAIP tools for teachers comes later.
          • 
              
        • No student data. PAVE maps items to standards. It holds no scores.
          • 
              
        • Playbook rules are not calculated. The 90% alignment and 80% agreement rules from the PAVE playbook are shown for reference only.
          • 
              
        • No AI grammar checking. Wording is not rewritten or checked by AI.
          • 
            
        
          
        
        
        
        
        
          LATER PHASES
        Planned, not in this version
        
          
          
            
        • Basic spell check: a plain dictionary check on proposed wording, with no AI. Still to be decided.
          • 
            
        • Download and export: so a state can take its standards with it.
          • 
            
        • Integrations: mappings exported to Smarter Balanced reporting and IAIP tools for teachers.
          • 
            
        • Content Explorer: over about six months, bring in Content Explorer's resources so each state has its own version, with an edit button for people allowed to make changes.
          •
